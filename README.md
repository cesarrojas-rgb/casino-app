# 🎰 Casino App - Interfaz Gráfica con TCL/TK y Python

Proyecto desarrollado para la asignatura **Aplicaciones y Lenguajes de Código Abierto**. El objetivo es maquetar la interfaz gráfica de usuario (UI) modular para una aplicación de casino, implementando un flujo colaborativo mediante control de versiones en Git y GitHub.

## 📁 Estructura del Proyecto

```text
casino_app/
├── main.py               # Punto de entrada de la aplicación
├── config.py             # Configuración global de estilos y colores
└── modules/
    ├── __init__.py
    ├── slots.py          # Módulo de la máquina tragamonedas
    └── roulette.py       # Módulo del tablero de ruleta
